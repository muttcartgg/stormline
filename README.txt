STORMLINE RADAR — install on iPhone

1. Put these files online (free, one time):
   a. Sign in at github.com (free account) and create a new public repository named "stormline".
   b. Tap "uploading an existing file" and upload every file in this folder.
   c. Open the repo's Settings > Pages, set Source to "Deploy from a branch", branch "main", folder "/ (root)", Save.
   d. After a minute your app is live at https://YOUR-USERNAME.github.io/stormline/

2. On your iPhone, open that link in Safari.
3. Tap Share > Add to Home Screen > Add.
4. Open Stormline from the home screen and allow location when asked.

To update the app later, upload the changed files to the same repository.

No API keys needed. Data: NEXRAD radar, storm attributes, storm reports, GOES satellite and HRRR from the
Iowa Environmental Mesonet; alerts and forecasts from the National Weather Service.
Not an official warning source.
